# Fitness AI Hub

Garmin + Supabase + GitHub Pages + Puter AI health dashboard.

## Features

- Supabase login/register
- Garmin health data storage
- Garmin scraper support
- Dashboard for:
  - Weight
  - Target weight
  - Steps
  - Resting heart rate
  - Stress
  - Activities
  - AI readiness
- Puter AI body condition analysis
